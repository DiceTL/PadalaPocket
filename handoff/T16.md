### 2026-11-23 — local cancellation fence implemented

- Added `20261123160000_t16_deposit_cancellation.sql`, cancellation/reconciliation paths in `apps/api/src/velo-topups.mjs`, `apps/api/scripts/verify-deposit-cancel.mjs`, check registration and the API syntax-check entry. - The migration adds `cancelled_at`, `cancellation_state` (`none`, `fenced`, `late_paid`, `resolved`) and `cancellation_checked_at`; it also adds the coordinator-only `admit_velo_deposit_credit` RPC. T15 now uses that RPC so reservation and cancellation serialize on the same deposit row.
- `npm run verify:backend -- deposit-cancel`: **PASS** against loopback Postgres and the real handler, with simulated Velo/Horizon. It covers:
  - a pending deposit without a checkout cancels immediately, is idempotent, and releases admission;
  - a created checkout cancellation hides the URL, keeps the underlying status non-terminal, and blocks a replacement deposit;
  - a fenced checkout whose Velo intent expires becomes `resolved` and permits a replacement;
  - a late paid intent after cancellation is retained as `late_paid` with verified receipt evidence, remains non-spendable, blocks replacement, and `creditVeloDeposit` rejects it with `DEPOSIT_CANCELLED` and zero `money_operations`;
  - a paid/verified deposit is refused with `CONFIRMED`; a paid-but-unverified receipt is refused with `PAYMENT_STARTED`;
  - unknown status stays blocked, another parent gets `NOT_FOUND`, and an admitted T15 credit gets `CREDIT_STARTED`;
  - a concurrent cancel/credit race has exactly one winner: either cancellation fences and credit rejects, or credit admits and cancellation is refused; it never cancels and credits.
- The check was added alongside the implementation rather than as a separate red-first run. Its first complete run passed; adding the concurrent race assertion initially failed on the valid `CONFIRMED` alternative winner, then was corrected to assert the exactly-one-winner invariant.
- Adjacent checks after the change: `deposit-receipt` **PASS**, `deposit-admission` **PASS**, `deposit-credit` **PASS**, `environment` **PASS**. Focused T15 unit tests: 4 **PASS**; `check:contracts` **PASS**; API workspace build **PASS**; `git diff --check` clean.
