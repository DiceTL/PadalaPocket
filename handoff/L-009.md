# L-009 — Installable PWA

Authorized by DEC-091 and DEC-082. Task status belongs in docs/implementation-plan.md.

Plan and scope:
1. Add public manifest, 192/512 icons including maskable, Apple touch icon, metadata and offline document.
2. Register a native worker in production only. Cache only the public offline document; intercept only same-origin non-API navigations and fall back on network failure. Never cache live HTML, Auth, APIs or photos. Updates wait for existing windows to close.
3. Add an install action when the browser offers a prompt, manual install help otherwise, standalone hiding and a connection notice. Preserve existing styling and account/payment limits.
4. Build and check manifest/assets, worker privacy boundaries, offline/reconnect, update waiting and responsive controls using Chromium. Physical mobile installation remains a human acceptance check.

Files: apps/web/public/{manifest.webmanifest,sw.js,offline.html,icons/*}, src/pwa.js, index.html, main.js, styles.css, Vercel cache headers and relevant documentation.
