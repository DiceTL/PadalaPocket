## Work

Create npm workspaces for web/API, root install and per-workspace run/check scripts, ignore rules, sanitized environment documentation and minimal deployment routing. Establish the test tools/scripts both developers will use. Document file ownership and branch/merge rules. No product screens or speculative shared library. Establish an automated PR workflow for clean install, contract checks, workspace tests and build. Record exact local/CI commands; a deliberately failing check must make the workflow fail. Configure required checks when repository permissions allow; otherwise explicitly require manual verification of green CI before merging. Keep live-provider checks out of ordinary PR CI.

## Acceptance and required checks

- [ ] A fresh clone installs from the committed lockfile and runs both workspace checks using documented commands; no secret enters tracked files/browser output; Testnet configuration and deployed Node checks are documented.
- [ ] Record actual commands once created.
- [ ] Record exact commands established by S-001, their observed results and required manual/live evidence. Documentation-only work uses document checks with program tests marked not applicable and explained.
- [ ] Relevant automatic PR checks pass; other developer reviews; merged commit recorded. Mocked provider tests do not establish live integration success.
