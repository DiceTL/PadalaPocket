# Frontend capability reference

Adapted from the source workflow. Complements the agreed design and delivery guardrails.

## Visualization

Start with the user question. Use readable text or a table when sufficient.
Introduce charts only when they improve understanding; disclose units, source, and demo data.

## Streaming and partial state

Use ordinary requests or polling when sufficient. Introduce streaming only for an actual interaction need.
Distinguish in-progress, confirmed, failed, and unknown outcomes. Handle interrupted requests and retries.
Do not present a client animation as proof that an external operation succeeded.

## Citations and provenance

Attach source identifiers to actual supporting records. Preserve traceability through derived summaries.
Never manufacture citations. Distinguish evidence, inference, and proposal in product or research output.

These capabilities are optional; no chart, streaming transport, or citation UI is mandated by this guide.
