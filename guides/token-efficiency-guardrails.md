# Session and editing hygiene

Adapted from the source workflow's token-efficiency guide.

- Keep one coherent workstream per session; start a fresh session for unrelated work when helpful.
- Read routing first, then only relevant files/sections. Give a builder the task packet and its necessary references.
- Use targeted searches and small patches instead of repeatedly reading or rewriting whole documents.
- Keep source-of-truth ownership clear; avoid duplicated requirements and progress trackers.
- Before handing off, summarize the goal, files changed, decisions, remaining uncertainty, and next step.
- Keep always-loaded instructions short. Load optional guides and skills only when relevant.
- Exclude generated assets, dependencies, build output, and credentials from routine AI context.
- Follow repository checks; do not substitute smaller context for needed evidence.
