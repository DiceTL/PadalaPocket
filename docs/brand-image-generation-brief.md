# PadalaPocket brand image generation brief

Use this brief with an image-capable AI chatbot. Generate **nine separate, full-color images**: three visual directions, with a brand board, parent dashboard, and student mobile screen for each. These are visual proposals for review by Hedrix, the human design owner—not approved changes to product requirements, Figma, or the application.

## How to use

1. Paste the **Shared instructions** into the image-capable chatbot. Attach a screenshot or export of the [Figma reference](https://www.figma.com/design/MJW4VcnqT8cntvEjtHUyMA/Untitled?node-id=0-1&p=f&t=i2TtcvFMbaMm4krK-0) if possible. The link's thumbnail shows the overall layouts; it is not a complete or authoritative specification of individual layers.
2. Paste one of the nine prompts below at a time. Generate the brand board first, then use that image as a visual reference for the other two images in the same direction.
3. Review each image before continuing. Correct spelling, illegible labels, inconsistent colors, misleading states, or invented features; use the exact hex values in the brief as the authoritative proposed palette, not sampled AI output.
4. Compare the three directions; ask the human designer to select or revise one. Do not implement a direction solely because it appears in a generated image.

## Shared instructions

> You are a product designer creating high-quality visual concepts for **PadalaPocket**, a family allowance application. There are parent desktop views and student mobile views. The parent can review purchase requests; the student can choose Needs or Wants and prepare a purchase for review. Create nine separate, full-color images, using the requested direction and image prompt each time. Use any attached Figma screenshot as a layout reference, not permission to invent features.
>
> **Audience and tone:** Clear for parents, age-appropriate for teenagers, approachable, and credible. Avoid childish mascots, generic corporate illustrations, decorative clutter, gradients, 3D, device mockups, stock photos, and marketing claims. Use practical interface components, strong hierarchy, generous whitespace, and readable labels. Show the actual design canvas or screen directly.
>
> **Terminology and accuracy:** Use the exact category names **Needs**, **Wants**, **Savings**, and **My Money**. My Money is private to the student: never show its balance in a parent view. Mark example figures and activity **Sample data**; example peso amounts are illustrative, not real transactions. Clearly label Waiting, Paid, and Failed; a waiting or unknown payment must never look paid. Do not invent features, transaction outcomes, testimonials, trust claims, compliance claims, or product policies.
>
> **Visual quality:** Produce crisp, legible, polished UI rather than wireframes. Prefer accurate short text to dense or fabricated copy. Maintain consistent colors, type, shapes, icon style, and spacing across each direction's three images; make the three directions visibly distinct. Use the given hex codes as targets. Favor high-contrast text and labeled status indicators; never rely on color alone. Accessibility is a design objective, not a claim of verified compliance.
>
> **Composition:** Brand boards should be landscape and include labeled swatches, typography, and component examples. Parent dashboards should use a landscape desktop composition with a left sidebar. Student screens should use a portrait mobile composition, with readable touch controls and bottom navigation. Avoid tiny or cropped interface text. Any icon or wordmark is a concept, not a finished logo or trademark-cleared asset.

## Direction 1 — Calm & Trustworthy

**Intent:** Restrained, reliable, and closest to the existing blue-led reference; structured cards and quiet borders.

**Proposed palette:** Deep navy `#16324F`, primary blue `#176B9A`, pale blue `#E7F3F8`, white `#FFFFFF`, dark text `#172B3A`. **Type:** Inter. **Components:** subtle outlines, about 12px card corners, simple line icons, strong amount hierarchy.

### Image 1 — Brand board

> Create a full-color landscape brand kit board for PadalaPocket, direction **Calm & Trustworthy**, using its proposed palette and Inter typography. Include labeled color swatches with hex codes; heading, body, label, and amount type samples; a typographic wordmark concept; primary and secondary buttons; an input; a card; line icon examples; and distinct labeled Waiting, Paid, and Failed status treatments. Keep the composition refined, functional, readable, and consistent with the shared instructions.

### Image 2 — Parent desktop

> Create a full-color landscape **parent dashboard** using the Calm & Trustworthy brand board as reference. Show a left navigation sidebar, a welcoming heading, separate Needs and Wants overview cards, and a **Needs your review** section with one sample request and a **Review request** button. Include **Sample data**. Keep the parent view free of private My Money balances; do not invent completed payments. Apply the same palette, typography, borders, and card styling as the brand board.

### Image 3 — Student mobile

> Create a full-color portrait **Pay a seller** student screen using the Calm & Trustworthy brand board as reference. Show Needs and Wants selection, an item-photo attachment area, a price field, a clear action button, and bottom navigation labeled Home, Activity, Savings, and My Money. Include **Sample data**. Use spacious touch targets and consistent blue styling; show no fake transaction completion.

## Review before using

- Check all nine images exist and each direction looks internally consistent but distinct from the others.
- Check legibility, spelling, color usage, category terminology, sample-data labels, privacy, and honest payment states. AI-generated interface copy and hex codes can be wrong.
- Verify actual text/background contrast, focus states, keyboard use, and touch sizes in the implementation; an image cannot establish accessibility compliance.
- The image generator may add controls or alter flow details. Treat those as visual artifacts, not requirements. Refer to [design-brief.md](design-brief.md) for the established design context and design authority.
