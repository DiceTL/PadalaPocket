# PadalaPocket mascot image generation brief

Use this brief **after** generating the brand directions in [brand-image-generation-brief.md](brand-image-generation-brief.md). Create three separate, full-color mascot concepts: one informed by each direction's generated brand board and interface images. These are proposals for Hedrix, the human design owner, to review—not an approved mascot or a product requirement.

The initial concept is **Piko the Pocket Eagle**: a small, rounded eagle with a calm, watchful expression. This is a proposed direction, not a finalized character.

## How to use

1. In an image-capable chatbot, attach the generated brand board and, if available, the parent and student screens for the direction being explored. Identify the direction by name.
2. Paste the shared prompt below, followed by one of the three direction prompts. Generate each concept as a separate image.
3. Repeat with the corresponding references for the other directions. Let their generated palettes, typography-adjacent visual character, shapes, and icon treatments guide each mascot. **Do not impose a separate fixed color palette:** use the actual generated direction as the visual reference.
4. Compare the concepts with the human designer. Refine a favorite using its generated image as a reference; a generated character is not a finalized, original-rights-cleared asset.

## Shared prompt

> Design **Piko the Pocket Eagle**, an original mascot concept for PadalaPocket, a family allowance application used by parents and teenagers. Piko is a small, rounded eagle with a compact silhouette, softly folded wings, clean feather shapes, a neat crest, and a calm, watchful expression. Add a subtle pocket shape on the chest with a tiny ₱ detail; avoid turning the character into a walking logo. Keep the beak and talons simple, friendly, and free of sharp or aggressive shapes.
>
> Use the attached brand board and UI concepts as the visual reference. Adapt Piko's main feathers, small accent, face, and chest to the generated direction's palette. The initial idea used deep blue feathers, a mint accent, and a warm white face and chest, but these are illustrative—not fixed colors for every direction. Derive the line treatment and visual personality from the reference too.
>
> Create one polished, full-color mascot concept sheet: show a large, clear full-body character and two smaller expressions or poses of the **same** character, such as calmly watching a pending request and gently guiding a student. Include a small example of the mascot beside a neutral app card to show scale; the mascot must not obscure labels, controls, or financial information. Keep the composition clean, legible, and suitable for later refinement by a designer.
>
> Piko should suggest attentiveness and reassurance, while feeling appropriate for teenagers and parents. Favor a recognizable silhouette, simple reproducible shapes, and restrained detail. Do not imitate a recognizable existing mascot, copyrighted character, or logo. No 3D rendering, stock photography, visual clutter, or illegible decorative text.
>
> Do not invent features, testimonials, security claims, or financial outcomes. Reserve celebratory poses for confirmed outcomes; do not use Piko to imply a pending payment has succeeded or a request has been approved. Any sample UI content must be labeled **Sample data**. The mascot is a visual concept, not an accessibility substitute: essential instructions and statuses must remain explicit in text.

## Review before using

- Check that each mascot belongs visually to its own generated brand direction and remains recognizable at small sizes.
- Check consistency across poses, suitability for parents and teenagers, and that no example suggests a real or successful transaction.
- Review similarity to existing characters and any rights or trademark questions before adoption. AI output does not establish ownership or clearance.
- Confirm the human designer's choice before adding the mascot to Figma, product copy, or the application.
